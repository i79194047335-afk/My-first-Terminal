# hypothesis/ — исследование всплесков

Черновики, на которых калибровался индикатор. Прод-код — в `core/shock_detector.py`
и `core/news_windows.py`; здесь только то, чем считались пороги и проверялись гипотезы.

M1 берётся из тикового архива `data/*.csv`, а не из `market.db`: в БД окно 2000
баров на ТФ (~33 часа M1), двух недель там нет.

| Файл | Что делает |
|---|---|
| `correlation_divergence.py` | Посвечное сравнение EU/UJ, одно окно. Первый прогон 16:15–16:30. |
| `correlation_divergence_v2.py` | То же + режим рынка (60 свечей: тренд/боковик/сжатие). |
| `uj_shock_reversal.py` | Проверка разворота после всплеска. Общие хелперы (`load_series`, окна) — отсюда. |
| `uj_shock_today.py` | Тот же скан за один день. Аргумент — дата `YYYYMMDD`. |
| `calibrate_sigmas.py` | Пороги по парам: распределение z-score, p99.9, частота событий. |
| `preview_signals.py` | Реплей архива через прод-классы: что ушло бы на фронт. |

## Главный результат

**Эджа в развороте после всплеска нет.** При 10σ за две недели — 7 событий,
разворот 42.9% против базовой частоты смены цвета 52.0% (0.5 s.e.). M1-форекс
и так меняет цвет примерно в половине случаев — любую проверку «развернётся ли»
обязательно сравнивать с этой базой, иначе 43% можно принять за сигнал.

Индикатор поэтому отмечает НЕОБЫЧНУЮ свечу и не предсказывает направление.

## Пороги (21.07–03.08, p99.9 каждой пары)

| Пара | Порог | Максимум за 2 недели |
|---|---|---|
| USD/JPY | 8.0σ (закреплено владельцем) | 13.3 |
| AUD/USD | 5.0σ | 11.1 |
| USD/CAD | 4.5σ | 6.6 |

Единый порог 8σ не годится: USD/CAD до него не дотягивается вообще. Сигма меряет
редкость события внутри своей пары, а не размер движения.
